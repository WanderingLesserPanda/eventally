# Eventally

> It all adds up. Eventually.

An app for tracking spending, keeping your books, and splitting expenses with friends.

## Why “Eventally”?

**Eventually + Tally = Eventally.**

Born from the recurring question: *“Why doesn't this tally?”*

The name is a small promise that, after finding the missing transaction, fixing the duplicate entry, and checking everything for the fifth time, the numbers will finally agree.

There's a little **“even”** in there too—because settling up should leave everyone even.

**Good friends. Clear accounts. Eventually.**
